# PlayVerse

A responsive, static browser-game portal built with HTML, CSS and vanilla JavaScript. No build command or package installation is required.

## Included games
- 2048 — keyboard controls
- Neon Snake — arrow keys and WASD
- Memory Match — randomized matching pairs
- Tic Tac Toe — player vs. computer

## Run locally
Open `index.html` in a modern browser, or use VS Code Live Server.

## Cloudflare Pages deployment
Connect this GitHub repository in Cloudflare Workers & Pages. For a static site, leave the build command empty and set the output directory to the repository root (`/`). Use `main` as the production branch.

## Before launch
Only publish games and assets you have the rights to distribute. Add privacy, terms and contact pages and follow the current ad-network policies before applying for monetization. Approval and revenue are not guaranteed.
